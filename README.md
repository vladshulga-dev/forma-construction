# ФОРМА

Одностраничный сайт строительной компании с акцентом на крупные проекты, понятную структуру услуг и портфолио выполненных объектов.

На странице представлены основные направления компании, примеры коммерческого, промышленного и инфраструктурного строительства, а также подход к ведению проекта от подготовки до сдачи.

## Возможности

- адаптивная верстка для компьютеров и мобильных устройств;
- фильтрация проектов по направлениям;
- полноэкранный просмотр фотографий проектов;
- мобильное меню;
- плавная навигация по разделам.

## Стек

HTML, CSS, JavaScript.
